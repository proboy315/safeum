
# 🔐 Safeum - Setup & Execution Guide

Welcome to the **Safeum Tool**!

This tool is designed to run in **Termux**, and requires some initial setup before execution. Follow the steps below **step-by-step** to get started.

---

## 📦 Step 1: Install Git

> Git is required to clone the repository. Run the command below:

```bash
pkg install git -y
```

---

## 📥 Step 2: Clone the Repository

> Use the following command to download the Safeum project from GitHub:

```bash
git clone https://github.com/proboy315/safeum.git
```

---

## 📂 Step 3: Enter the Project Folder

```bash
cd safeum
```

---

## 🛠️ Step 4: Run the Setup Script

> This script will install all required packages and dependencies:

```bash
bash run.sh
```

---

## 🚀 Step 5: Run the Main Script

> Once the setup is complete, use the command below to launch Safeum:

```bash
python safeum.py
```
